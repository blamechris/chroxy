## Preconditions and method

- **Key.** `docs/reports/harness-evals/trial/eval/KEY.md` at `trial/eval` commit `7b92999d`: `sha256sum` = `fb5599f33ddac7eb230b7edc29f0fefd5b3be7c39c746bf5dcd7055d24d40f23`, 7782 bytes. Matches `KEY-COMMITMENT.md` on `origin/main` exactly. No incident.
- **T0.** `git merge-base origin/trial/<base> origin/main` = `932bd3a4ef40bc9634cab390e6cf0facadd801d7` for every run base (all eight). Every diff below is the squash commit on the run's base over T0 (or the PR head, for PRs never merged), read with `git show`; nothing was run, no mutation was executed.
- **Issue acceptance criteria** come from the ten issue bodies read through the GitHub API; **correctness** is judged against `KEY.md`'s "Acceptance checks" as the pass bar and "Expected root cause" as the right-fix test. `yes` = every acceptance check met by the diff; `partial` = the change is sound but a named check is missed; `no` = wrong or harmful.
- **GitHub metadata** (reviews, comments, review threads, commits, Actions runs, check runs) was collected read-only through the GitHub MCP tools, every PR of every run. "Copilot bodies" counts `copilot-pull-request-reviewer[bot]` review submissions; "owner-account bodies" counts reviews submitted by `blamechris` plus issue-style PR comments by `blamechris` (the merge-gate review comments the runs post), reported as `reviews + comments`. "CI runs" counts `ci.yml` runs on the PR's head branch (every run, including cancelled and failed); Repo Relay and the Copilot dynamic run are not counted.
- **Red CI on the base after merge:** `.github/workflows/ci.yml` at T0 and on `main` today has `on.push.branches: [main]` only; `list_workflow_runs` with `event: push` on each `trial/*` base returns 0 runs. The measure is **not observable** for every run; it is never reported as 0.
- **Isolation audit** inputs: PR titles, bodies, commit subjects, review and comment bodies (all collected verbatim), the run reports' self-reports, and the README status rows. **No transcripts were attached in `mailbox/attachments/` on `trial/eval`** (the folder holds only the earlier diagnostic's `Report.md`), so every "read of another trial/*, of `KEY.md`, of a `NEXT-*.md` seed" entry below rests on the run's self-report and on what the PRs show, and is marked `self-report only`. Human approvals are counted from the run report and the README row (the permission journal was not attached).
- **Byte-identity** was checked with `sha256` over `git show --format=` of each squash commit (whole diff, and the diff restricted to non-test source files with `index` lines stripped), and per source file across runs for the same issue.
- Cycle = PR `created_at` → `merged_at`, minutes. Median is the standard median, p90 the nearest-rank (`ceil(0.9n)-1`, 0-based) value.
- Where a claim could not be verified from GitHub or the branches it is marked **unverified**.
